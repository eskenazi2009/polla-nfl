# Polla NFL · dashboard

Piques de Kvetchers y KIBBEH en la Polla Panamá 2026 (Splash Sports, pick'em contra el spread).

Página: https://eskenazi2009.github.io/polla-nfl/

- `extract.js`: se ejecuta en el navegador con la sesión de Splash y devuelve los datos en JSON.
- `build.py`: mezcla los datos en `data/store.json` y genera `index.html`.
- `template.html`: diseño del dashboard.
- `ACTUALIZAR.md`: pasos que siguen las tareas programadas de Claude.
